# School-system-management
## Description
School Management System is a Python-based application designed to help schools manage student information and school-related activities easily.
The system allows users to add, view, search, update, and delete student information. It is designed to make school data management simple and organized.
## Programming Language
- Python
## Features
- Add students
- View students
- Search students
- Update student information
- Delete students
